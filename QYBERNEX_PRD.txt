1. PRODUCT IDENTITY

2. OBJECTIVE
QYBERNEX is a unified cybersecurity platform that brings together threat intelligence, incident response, monitoring, deception, and secure operations into a single modular experience. The product is designed to help security teams detect, prioritize, investigate, and respond to cyber threats across desktop and mobile environments.

3. PRODUCT VISION
The platform should eventually include:
1. CyberDesk — unified security dashboard
2. AI Threat Intelligence — analysis and risk scoring
3. IDS/IPS — intrusion detection and prevention integrations
4. SIEM — centralized security event management
5. Cyber Deception — isolated honeypots and decoy services
6. Endpoint Security — monitoring and alerts
7. Vulnerability Management — authorized asset assessment
8. Incident Response — investigation and response workflows
9. Quantum-Safe Evidence Vault — ML-DSA / ML-KEM based evidence handling
10. QYBERNEX Autopilot — controlled AI-assisted operations
11. Super Admin Control Center — centralized administration
12. User and Tester Portals — separate role-based experiences

4. PRINCIPAL GOAL
Deliver a professional, modular, extensible security operations platform with secure architecture, responsive user experience, and platform-aware delivery across modern desktop and mobile operating systems.

7. SECURITY REQUIREMENTS
The platform must include:
- secure authentication
- password hashing using a modern password hashing algorithm
- role-based access control
- server-side permission enforcement
- secure session management
- input validation
- rate limiting
- audit logging
- secure HTTP headers
- CORS restrictions
- CSRF protection where applicable
- secrets management via environment variables
- secure error handling
- dependency and vulnerability review

The platform must not:
- expose unrestricted shell access to an AI agent
- allow arbitrary command execution by AI models
- permit unauthorized network scanning
- connect isolated honeypots to sensitive production systems
- store real credentials in decoy services
- grant unrestricted permissions to automated response actions
